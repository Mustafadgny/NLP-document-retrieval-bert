# 🔎 Semantic Search & Information Retrieval with BERT

This repository demonstrates how to build an Information Retrieval (IR) and Semantic Document Similarity pipeline using dense text embeddings generated by a pre-trained BERT model (`bert-base-uncased`) and Cosine Similarity.

## 🚀 Overview

Traditional keyword search fails when users ask questions with synonyms or conceptual overlaps. This project generates dense, contextual embedding representations for a corpus of documents and a target user query, then computes mathematical similarity using Cosine Distance to rank the most relevant documents.

## 🧠 Technical Pipeline

1. **Tokenization & Padding:** Processes documents and queries dynamically using `BertTokenizer` with truncation and padding.
2. **Contextual Representations:** Feeds input token tensors through `BertModel` to extract the `last_hidden_state`.
3. **Mean Pooling:** Calculates sentence-level representations by taking the mean across the sequence length (`last_hidden_state.mean(dim=1)`).
4. **Similarity Ranking:** Computes pairwise cosine similarity between query vectors and stacked document embeddings using Scikit-Learn.

## 🛠️ Tech Stack
- Python
- PyTorch
- Hugging Face Transformers (`bert-base-uncased`)
- NumPy
- Scikit-Learn

## 💻 Installation & Usage

1. Install dependencies:
pip install torch transformers numpy scikit-learn

2. Run the script:
python ir_bert.py

## 📊 Example Retrieval

- **Query:** "What is machine learning?"
- **Target Corpus:** Multiple sentences covering Artificial Intelligence, Machine Learning, Deep Learning, and an irrelevant sentence ("I go to shop").
- **Output:** The script ranks documents according to semantic relevance score, assigning high similarity to related machine learning definitions and minimal score to unrelated sentences.
